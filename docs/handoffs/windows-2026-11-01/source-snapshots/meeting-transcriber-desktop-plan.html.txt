<details><summary>Implementation boundaries that matter</summary>
<h3>Reuse the file owners; do not create a second source of truth</h3><p>Project the library from existing bundle folders and <code>transcript_run.classify</code>. The library combines live job state with durable file state, and does not declare a transcript ready just because JSON appeared. Use the stronger <code>validate_managed_run</code> boundary before cleanup actions. Keep run ordering compatible with the current latest-run selection.</p><p>Begin with an in-memory library index and refresh/rescan. Add a rebuildable search cache only if measured library size requires it. No database, account service or sync engine is needed for your selected folder-copy workflow.</p>
<h3>Render canonical segments, stream local audio</h3><p>The saved JSON already has segment timestamps, speakers and word timing. The current HTML joins adjacent same-speaker segments into a single passage, even across gaps. A linked viewer must retain each original segment’s time range inside any visual grouping. Derive playback duration from the media, not just the last spoken word.</p><p>Resolve a regular, non-symlink source recording inside the selected bundle. Do not hardcode <code>recording.wav</code>: imports preserve other extensions. An ambiguous or unsupported source should show a clear limitation and offer the original file; it must not select arbitrary media. Add a derived playback copy only if real codec failures justify it.</p><p>Use a scoped URL with HTTP range support for streaming; do not pass a whole long WAV through JSON or base64. Keep portable HTML/Markdown exports useful without the desktop app. Opening a copied HTML file alone must not imply that its audio was copied too.</p>
<h3>Keep remote lifecycle behavior visible</h3><p>The existing provider owner publishes local JSON/Markdown/HTML before confirming remote deletion. “Transcript ready; remote cleanup needed” is a usable result with follow-up work, not a missing transcript. Keep API keys and provider cleanup identifiers out of transcript markup. On restart, surface interrupted attempts for inspection rather than blindly uploading again.</p><p>A GUI Cancel button is not a keyboard interrupt. Introduce cooperative cancellation in the actual job owner and retain its cleanup path. Allow bounded network calls to finish or time out while showing “Cancelling.” Stop FFmpeg gracefully, check the recording and only then finalize it. Do not depend on Windows process termination running cleanup.</p>
<h3>Keep the bridge and private files narrow</h3><p>Expose bounded actions such as list meetings, load transcript and start a known operation. Do not expose arbitrary shell commands or unrestricted filesystem paths to the page. Escape transcript content, reject path traversal, and never load legacy or remote HTML in a privileged bridge window. A localhost media/REST route needs scoped access and appropriate request protection.</p><p>Desktop credentials need a private per-user configuration location outside the installed app. Preserve the current strict parsing and containment intent; do not quietly restore the OS-keychain scheme recently removed in the repository. Leave the source CLI’s checkout <code>.env</code> behavior intact until a shared migration is deliberately selected. Windows privacy must use and verify ACLs: Python’s <code>chmod</code> is not a substitute for POSIX file permissions there.</p>
<h3>Keep mutable metadata explicit</h3><p>Use the existing canonical speaker-name map. Serialize saves through a shared operation, reload the current transcript and detect stale input before applying a name patch. JSON and its generated views are not one atomic transaction today; expose an export-refresh failure and allow retry without losing the canonical edit.</p><p>Capture/import titles can use the current bundle naming convention. Treat the folder timestamp as “Added” unless recording provenance is known; an imported file’s folder date is not its original recording date. Defer free-form notes, arbitrary title edits and corrected dates until there is a selected need for explicit bundle metadata. Unknown fields inserted into canonical JSON are discarded by its current serializer.</p>
