<h2>Behavioral acceptance</h2>
<ol>
<li><strong>Layout and controls.</strong> A compact top row provides Library, selected title, Find, Details and a secondary actions menu. The transcript and stable bottom audio transport occupy the remaining space. Metadata, language and saved-run selector belong in Details; speed, Follow and Jump belong in Listening. Avoid duplicate brand/header rows, permanent empty status headings or redundant descriptive footers. Use the existing color tokens. Long titles may truncate in the toolbar with full title accessible by tooltip/Details; long paths/run labels wrap safely. No additional raw date parsing or invented duration/participant/snippet metadata.</li>
<li><strong>Library.</strong> Open by default on wide windows; a named button collapses/restores it without changing selection, playback, query or run. On narrow windows (around the study's 760px responsive boundary), use one pane at a time, initially reader with Library available; selection returns to the reader and focuses its title. Escape/close returns focus to the Library opener. On entry into narrow mode do not leave an unexpected covering pane open. Presentation choices are session-only. A hidden library's read/access errors must remain discoverable through visible feedback and a clear Library recovery entry.</li>
<li><strong>Scanning.</strong> Keep title search always available in Library and group folder path/Choose/Refresh in its folder control. Add one Show dropdown: All; Transcripts (eligible run, including saved HTML fallback); Audio only (exact Recording saved status); Needs attention (cleanup-unconfirmed, unfinished, incomplete/unavailable status). Filters intersect literal case-insensitive title search and preserve backend order. Display shown/total counts honestly. Historical alone is not an error, and media ambiguity/missing is not inferred before loading. Keep Added labels and exact status qualifiers, including warnings, on rows. Choosing clears title search as before; refresh preserves search and surviving meeting/run selection. Picker cancellation preserves the current library.</li>
<li><strong>Find.</strong> Closed initially. The button and ordinary native-button keyboard activation open a shelf with literal passage-text search, previous/next, matching count and canonical speaker dropdown. Enter/Shift+Enter retain wrapping navigation. Closing the shelf preserves filters and leaves separate visible Text and Speaker chips, passage count and individual clear/clear-all actions. Speaker chips retain canonical IDs even when display names repeat. Hide redundant chips while the shelf itself is open. Clearing one filter preserves the other and returns focus to an available control. Global Ctrl/Cmd+F is optional only if it works in the real supported host; it is not a substitute for a visible keyboard-operable Find button.</li>
<li><strong>Details and selected version.</strong> Closed initially. Selected non-default run label/status remains visible when Details closes; label it as a selected saved version without claiming parsed chronology. Status follows the selected run; library rows follow the default. Keep Open saved HTML for that exact selected run in the actions menu, with a direct, prominent action in the structured-text-unavailable fallback. Closing Details never changes a run or pauses audio. Disclosure state may remain session-local across selection; existing query, speaker, scroll, speed and media reset behavior on selection must remain intact and derived labels must update.</li>
<li><strong>Listening.</strong> Core native transport, Back 10 and its error/loading reason remain available outside the collapsed Listening group. The closed Listening label exposes non-default speed and Follow-on state. Follow starts off, Jump remains a distinct action, and manual scroll/navigation or search/filter changes release Follow as before. Collapsing any group does not stop playback, change speed/position or enable Follow. Retain hidden-playing and silence feedback outside the group and allow it to wrap.</li>
<li><strong>Preserved reader correctness.</strong> Keep escaped text and source-array ordinal identity, source order, individual start ≤ time &lt; end intervals, simultaneous overlaps and no active segment in gaps. Add small visible source passage numbers where status/reader context uses them; never substitute duplicate canonical IDs for ordinal identity. Passage/timestamp activation seeks and plays while text selection does not seek. Beyond-duration, removed/unsupported/missing/ambiguous audio leaves text/search available with honest disabled media actions. No autoplay on selection. Preserve generation guards so stale load/media/error replies cannot replace the current meeting or its disclosure labels.</li>
<li><strong>Failure and focus.</strong> Cleanup/historical/incomplete/unfinished warnings, load failures, library errors and media failures stay understandable when panels close. Normal metadata may move into Details; actionable warnings may not disappear there. Empty/no-results, recording-only and saved-HTML states remain useful. Hidden sections leave the keyboard tab order; named buttons expose expanded/selected state, focus remains visible, Escape closes the active disclosure and returns to its opener, and controls remain usable at wide/narrow sizes and both themes. Preserve system theme following until explicit session choice.</li>
</ol>
